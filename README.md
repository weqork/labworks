# Messenger

Локальный мессенджер для Windows. Бэкенд на Go отдаёт веб-интерфейс и хранит аккаунты и сообщения в отдельном PostgreSQL.

## Как использовать

1. В папке messengerfinal **`Start-PostgreSQL.exe`** запускает базу данных. **`Start-Messenger.exe`** запускает мессенджер. Сначала запустите базу данных.
2. Оставьте окно запуска открытым. Когда сервер запустится, откройте http://localhost:9090.
3. Чтобы остановить работу мессенджера закройте cmd, чтобы остановить работу базы данных используйте **`Stopr-PostgreSQL.exe`**, это выключит базу данных а имеющие данные выгрузит локально, чтобы при новом запуске базы данных они сохранились
