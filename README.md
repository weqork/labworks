# Messenger

Локальный мессенджер для Windows. Бэкенд на Go отдаёт веб-интерфейс и хранит аккаунты и сообщения в отдельном PostgreSQL.

## Как запустить

1. На GitHub нажмите **Code → Download ZIP** и распакуйте архив целиком.
2. Откройте папку `messengerfinal` и дважды щёлкните по **`Start-Messenger.cmd`**. При первом запуске автоматически создаются пустая база `messenger` в папке `data` и файл настроек `.env`. Это может занять около двух минут. При повторном запуске используется та же база.
3. Оставьте окно запуска открытым. Когда сервер запустится, откройте [http://localhost:9090](http://localhost:9090) и зарегистрируйте аккаунт.

Для запуска готовой сборки достаточно Windows x64. PostgreSQL уже находится в папке проекта, а Go понадобится только для пересборки.

## Проверка работы

1. Зарегистрируйте два аккаунта и отправьте сообщение от одного аккаунта другому.
2. Закройте окно мессенджера, снова откройте `Start-Messenger.cmd` и обновите страницу.
3. Войдите в аккаунт и откройте тот же чат. Сообщение должно остаться в истории.

## Раздельный запуск и остановка

- **`Start-PostgreSQL.exe`** запускает только базу данных.
- **`Start-Messenger.exe`** запускает только мессенджер. Сначала запустите PostgreSQL.
- Чтобы остановить мессенджер, нажмите **Ctrl+C** в его окне. Чтобы остановить базу, откройте **`Stop-PostgreSQL.exe`**.

Каталог `data` и файл `.env` хранятся локально и исключены из Git. Инструкции по пересборке есть в [README проекта](messengerfinal/README.md).
